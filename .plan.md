# Rowing Animation — Implementation Plan

## Overview

A full-width parallax rowing scene inserted between the title header and metric tiles in `LiveMetrics.tsx`. The rower bobs gently when idle and rows at a speed matching the live stroke rate / pace during an active workout. Background layers scroll at different speeds for a parallax depth effect.

## Component Architecture

### New files
- `dashboard/src/components/RowingScene.tsx` — the full animation component
- `dashboard/src/components/RowingScene.css` — keyframes and layer styles (keeps index.css clean)

### No new dependencies
All animation uses CSS transforms + `requestAnimationFrame` for parallax offset. No canvas, no animation libraries — keeps bundle small and Pi-friendly.

---

## Technical Design

### 1. Container
- Full width, fixed height: **80px mobile / 100px tablet**
- `overflow: hidden`, `position: relative`
- Inserted between the title `<div className="mb-5 ...">` and the metric grid in `LiveMetrics.tsx`
- Rounded corners (`rounded-2xl`) with subtle border to match card aesthetic

### 2. Parallax Scrolling
- Each background layer is a wide SVG/div (2–3x viewport width) that translates on X via CSS `transform: translateX()`
- A single `useRef` tracks cumulative distance (`totalOffset`)
- On each animation frame, offset increments based on current pace:
  - **Idle/no metrics**: offset doesn't change (rower just bobs)
  - **Active rowing**: `speed = basePx / (pace_s_per_500m / 120)` — faster pace = faster scroll
  - Each layer multiplies by its parallax factor (0.05, 0.15, 0.35, 0.7)
- Uses `requestAnimationFrame` with `will-change: transform` for GPU compositing
- Layers wrap seamlessly using `% tileWidth` so the scene loops infinitely

### 3. Rower Character (Layer 1)
- Simple SVG rower in a boat, centered horizontally, sitting on the water line
- **Idle state**: gentle `bobbing` keyframe (translateY ±2px, slight rotate ±0.5°, 3s ease-in-out infinite)
- **Rowing state**: `rowing` keyframe that cycles the rower's arm/oar position through catch → drive → finish → recovery
  - Animation duration tied to stroke rate: `duration = 60 / stroke_rate` seconds
  - When stroke_rate is 0 or null, falls back to bobbing animation
- The boat stays horizontally centered — the world moves around it

### 4. Water Surface (Layer 2)
- Semi-transparent wave pattern overlay using repeating SVG or CSS gradient
- Scrolls with parallax at 0.7x speed
- Small wake/splash elements behind the boat that appear only when rowing (opacity transition)

### 5. Background Layers (3, 4, 5)
- **Layer 5 (sky)**: Static CSS gradient (dark blue-gray, matching dark theme). Optional slow-drifting clouds.
- **Layer 4 (distant mountains)**: SVG mountain silhouette in muted blue-gray, tiles horizontally
- **Layer 3 (treeline)**: SVG tree silhouette in darker green-gray, tiles horizontally

### 6. Color Palette (dark mode, matching existing theme)
- Sky: `oklch(0.22 0.02 250)` → `oklch(0.28 0.03 245)` gradient
- Distant mountains: `oklch(0.30 0.03 250)` with slight blue tint
- Treeline: `oklch(0.25 0.04 160)` dark forest green
- Water: `oklch(0.20 0.04 240)` deep water blue with lighter ripple accents
- Rower/boat: `oklch(0.55 0.10 48)` warm accent to pop against cool background

## Data Flow

```
LiveMetrics receives metrics + workoutState props
  └─> passes to <RowingScene>:
        - strokeRate: number | null  (effectiveStrokeRate)
        - pace: number | null        (metrics.pace_s_per_500m)
        - isActive: boolean           (workoutState === "ACTIVE")
        - isPaused: boolean           (workoutState === "PAUSED")
```

- When `isActive && pace > 0`: parallax scrolls, rowing animation plays at stroke rate
- When `isPaused`: parallax stops smoothly (decelerates), rower holds position
- When idle: no scrolling, gentle bob only

---

## Performance Considerations (Pi Zero 2W)

- **GPU-composited only**: All movement via `transform: translateX/Y` and `opacity` — no layout/paint triggers
- **`will-change: transform`** on moving layers
- **Single rAF loop** drives all layers (not per-layer timers)
- **SVGs are inline** (no image loads, no fetch overhead)
- **No canvas**: CSS transforms are more efficient for this simple scene
- **Reduced motion**: respects `prefers-reduced-motion` — disables parallax and rowing animation, shows static scene
- Target: < 2% additional CPU on Pi during active workout
